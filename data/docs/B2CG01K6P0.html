BVM MC ET BVM PILOTEE 6 RAPPORTS STT
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Opérations préliminaires
Effectuer une mise hors pression du circuit hydraulique .
Déposer le groupe électropompe .
2. Dépose
Figure : b2cg2csd
Vidanger le réservoir hydraulique (1).
Déposer :
  • Les vis (2)
  • Le réservoir hydraulique (1)
Figure : c5dp07dd
Déposer :
  • Les 3 vis (3)
  • Le moteur électrique
3. Repose
Figure : c5dp07ed
Vérifier l’absence de corps étrangers dans le logement du moteur électrique.
Reposer l’entraîneur (4) sur le doigt d’entraînement de la pompe (5).
Figure : c5dp07fd
Aligner le méplat de l’entraîneur (4) avec les deux taraudages ( en "a") ; À l’aide d’un tournevis.
ATTENTION : Nettoyer parfaitement les surfaces.
Figure : c5dm03kd
Tourner l’entraîneur du moteur (6) afin d’aligner le méplat avec les deux perçages ( en "b").
ATTENTION : Nettoyer parfaitement les surfaces.
Reposer le moteur électrique.
Figure : c5dp07hd
"A" : Montage incorrect.
"B" : Montage correct.
ATTENTION : Le moteur doit être bien plaqué sur la pompe (Montage "B").
S’il y a un jeu "C" entre les deux faces d’appui, l’entraîneur du moteur (6) n’est pas emboîté dans l’entraîneur (4).
Dans ce cas, déposer le moteur et refaire les alignements décrits plus haut.
Reposer les 3 vis (3).
Figure : b2cg2csd
Reposer le réservoir hydraulique (1).
Serrer les vis (2).
4. Opérations complémentaires
Reposer le groupe électropompe .
Effectuer la remise en pression et la purge du circuit hydraulique ; À l’aide de l’outil de diagnostic .
