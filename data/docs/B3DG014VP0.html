B3DG014VP0Dépose - repose : Train arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Un presse-pédale.
Un outil de diagnostic.
Outil de levage .
2. Dépose
2.1. Opérations communes
ATTENTION : Avant toute intervention sur les freins arrière, mettre en position de démontage l’ensemble étrier de frein motorisé ; À l’aide de l’outil diagnostic.
Lever et caler le véhicule sur un pont à 2 colonnes.
ATTENTION : Sangler le véhicule sur le pont élévateur.
Mettre l’étrier de frein motorisé arrière en position de démontage ; À l’aide de l’outil diagnostic.
Débrancher la batterie de servitude .
Placer le presse-pédale sur la pédale de frein, afin d’éviter l’écoulement du liquide de frein lors du désaccouplement des tubes de frein.
Déposer les roues arrière.
Figure : b3dg0opd
Déposer :
  • Les protecteurs (1)
  • Les protections sous caisse (2)
2.2. Véhicules équipés d’une commande de frein de stationnement électrique
Figure : b3dg0oqd
Opérations symétriques :
  • Déconnecter les connecteurs  (en "b")
  • Dégrafer et écarter les faisceaux électriques (en "a")
2.3. Véhicules équipés d’une commande de frein de stationnement mécanique
Figure : b3dg0q2d
Dégrafer le câble de frein de stationnement (3) (en "c").
Déposer la vis (4).
Figure : b3dg0q3d
Désaccoupler le câble de frein de stationnement (3) (en "e").
Dégager le câble de frein de stationnement (3) du guide-câble (en "d").
2.4. Opérations communes
Figure : b3dg0q4d
Opérations symétriques :
  • Désaccoupler le flexible de frein (6) (en "f")
  • Obturer la canalisation de frein ; À l’aide de l’outil [0194/2-E]
  • Déposer l’agrafe de maintien (5)
  • Déposer les ressorts de suspension arrière
  • Dévisser les vis de fixation du train arrière sans les déposer
Figure : b3dg0q5d
Positionner un outil de levage pour maintenir le train arrière.
Déposer la vis de fixation inférieure d’amortisseur ( de chaque côté).
ATTENTION : L’opération suivante nécessite deux opérateurs.
Déposer :
  • Les vis (8)
  • Le train arrière (7)
3. Repose
ATTENTION : Respecter les couples de serrage.
Couple de serrage :
  • Train arrière
  • Roues
3.1. Opérations communes
ATTENTION : L’opération suivante nécessite deux opérateurs.
Présenter le train arrière sous la caisse dans la même position que pour la dépose.
Reposer et serrer les vis (8).
Reposer la fixation inférieure d’amortisseur de suspension arrière (sans serrer) ( de chaque côté).
Opérations symétriques :
  • Reposer les ressorts de suspension arrière
  • Reposer l’agrafe (5)
  • Déposer les outils [0194/2-E]
  • Accoupler le flexible de frein (6) (en "f")
3.2. Véhicules équipés d’une commande de frein de stationnement électrique
Agrafer les faisceaux électriques  (en "a").
Connecter les connecteurs  (en "b").
3.3. Véhicules équipés d’une commande de frein de stationnement mécanique
Engager le câble de frein de stationnement (3) dans le guide- câble (en "d").
Accoupler le câble de frein de stationnement (3) (en "e").
ATTENTION : Contrôler le verrouilllage du câble de stationnement.
Agrafer le câble de frein de stationnement (3) (en "c").
Reposer la vis (4).
3.4. Opérations communes
Reposer :
  • Les protections sous caisse (2)
  • Les protecteurs (1)
  • Les roues arrière
Rebrancher la batterie de servitude .
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie de servitude.
Déposer le presse pédale.
Purger le circuit de freinage .
Mettre le véhicule en assiette de référence .
Serrer :
  • Les fixations inférieures d’amortisseurs
  • Les fixations (6) (Articulations élastiques de traverse de train arrière)
  • Reposer le véhicule sur ses roues
ATTENTION : Donner plusieurs coups de frein, doucement et progressivement, moteur tournant, avant de faire rouler le véhicule.
Contrôler le serrage des vis de roues.
Contrôler le niveau de liquide de frein et le compléter si nécessaire.
