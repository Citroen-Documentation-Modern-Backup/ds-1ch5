B3FG01LGP0Dépose - repose : Disque de frein avant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
IMPERATIF : Remplacer systématiquement les plaquettes de frein lors du remplacement des disques.
1. Outillage
Pince de type FACOM D60A.
2. Dépose
ATTENTION : Si le réservoir de liquide de frein est au niveau maximum, enlever son filtre et vidanger partiellement le réservoir à l’aide d’une seringue propre afin d’éviter son débordement.
Débloquer les vis de roues avant.
Lever et caler le véhicule, roues avant pendantes.
Déposer :
  • Les vis de roues avant
  • Les roues avant
Figure : b3fg2h7d
Déposer le ressort (1).
NOTA : L’utilisation d’un tournevis facilite le décrochage du ressort (1) (en "a").
Figure : b3fg2h8d
ATTENTION : Ne jamais désolidariser le flexible de frein de son support en "b". Risque de déterioration importante du flexible de frein.
Figure : b3fg2hkd
ATTENTION : Veiller à ne pas vriller le flexible de frein .
Déposer :
  • Les obturateurs  (en "c")
  • Les vis (2)
  • L’étrier de frein (3)
  • Les plaquettes de frein
NOTA : Les plaquettes de frein, côté intérieur de roue, sont clippées dans le piston de l’étrier de frein .
Figure : b3fg2had
Déposer :
  • Les vis (4)
  • Le support d’étrier de frein (5)
Figure : b3fg2hld
Déposer :
  • Les vis (7)
  • Le disque de frein (6)
3. Nettoyage
IMPERATIF : Ne pas utiliser d’air comprimé pour nettoyer les freins.
3.1. 1ère possibilité
Nettoyer le disque de frein (6) et l’étrier de frein (3) à l’aide d’un produit nettoyant frein recommandé.
Laisser égoutter et sécher.
Essuyer à l’aide d’un chiffon papier :
  • Le disque de frein (6)
  • L’étrier de frein (3)
3.2. 2ème possibilité
Utiliser un appareil de dépoussiérage homologué par le constructeur .
4. Contrôle
ATTENTION : Aucune trace de graisse, d’huile, de lubrifiant n’est tolérée sur les garnitures des plaquettes de frein.
Contrôler visuellement :
  • L’étanchéité autour du piston d’étrier de frein
  • L’ajustement et l’état des soufflets de protection
Remplacer les pièces défectueuses.
5. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Système de freinage
  • roues
Repousser le piston d’étrier à fond dans son logement ; À l’aide d’une pince (Type FACOM D60A).
NOTA : Intercaler une cale entre l’outil et la plaquette pour repousser le piston à fond dans son logement.
Surveiller le niveau de liquide de frein.
Reposer :
  • Le disque de frein (6)
  • Les vis (7)
  • Le support d’étrier de frein (5)
  • Les vis neuves (4)
  • Les plaquettes de frein neuves
  • L’étrier de frein (3)
  • Les vis (2)
  • Les obturateurs  (en "c")
  • Le ressort (1)
Vérifier l’accrochage du ressort (1) (en "a").
Reposer :
  • Les roues avant
  • Les vis de roues avant
  • Le véhicule sur ses roues
IMPERATIF : Appuyer doucement et progressivement sur la pédale de frein plusieurs fois, moteur tournant, avant de faire rouler le véhicule.
Contrôler le niveau de liquide de frein et le compléter si nécessaire.
