2. Dépose
Placer le véhicule sur un pont élévateur à 2 colonnes.
Déposer les roues avant.
Figure : c5jg1e2d
Déclipper l’agrafe  (en "a") ; À l’aide de l’outil [1350-ZZ].
Déposer les vis (2).
Dégager partiellement le pare-boue avant (1).
Figure : c5jg1e3d
Déclipper les agrafes (en "b") ; À l’aide de l’outil [1350-ZZ].
Déposer :
  • Les vis (3)
  • Le pare-boue avant (1)
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Serrer les vis de roues .
NOTA : Vérifier l’état des agrafes de fixation ; Remplacer si nécessaire.
