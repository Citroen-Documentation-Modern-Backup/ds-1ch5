C5JG01PBP0Dépose - repose : Pare-chocs arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Opérations préliminaires
Effectuer les opérations suivantes :
  • Ouvrir le volet arrière
  • Mettre le véhicule sur un pont élévateur deux colonnes
  • Déposer les pare-boue arrière (Partiellement)
2. Dépose
2.1. Pare-chocs arrière
Figure : c5jg1eud
Déconnecter les connecteurs  (en "a").
Déposer :
  • Les vis (2)
  • Les vis (4)
Dégager :
  • La fixation (3) (Suivant la flèche )
  • Le pare-chocs arrière (1)
Figure : c5jg1evd
Déclipper le pare-chocs arrière (1) (en "b").
Dégager le pare-chocs arrière (1) (Suivant la flèche ).
Déposer le pare-chocs arrière (1).
2.2. Supports de pare-chocs arrière
Figure : c5jg1ewd
NOTA : Suivant équipement.
Déconnecter le connecteur  (en "d").
Déclipper ; À l’aide de l’outil [1350-ZZ] :
  • Le faisceau électrique (5) (en "c")
  • L’antenne ADML (6)(Accès au Démarrage Mains-Libres) (en "e")
Déposer :
  • Le faisceau électrique (5)
  • L’antenne ADML (6)(Accès au Démarrage Mains-Libres)
Figure : c5jg1exd
Déposer :
  • Les vis (7)
  • Le support de pare-chocs arrière (8)
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Effectuer le réglage des jeux et affleurements.
Serrer les vis (2) et (7) à 1 m.daN.
Vérifier le fonctionnement des différents équipements.
